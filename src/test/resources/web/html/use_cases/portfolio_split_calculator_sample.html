Portfolio Split Calculator

Inheritance split of a securities depot into the parent's portfolio and one portfolio per child, respecting round lots. Children can be added and removed. Positions are walked from the largest tradable unit to the smallest; each rounding error is carried into the next position, so the cash at the end absorbs what is left. Preloaded with the sample bank report and its two children.

Notes

Rule per position. A child's target is its weight times the position value, minus the deviation carried in from earlier positions. That target in units is rounded to the nearest round lot. With mirroring on, every child receives the first child's count. If the rounded counts together exceed the position, every child gets at most an equal part in round lots. The parent gets the rest, so every original position is conserved exactly.

Deviation. The carried deviation is the realised value minus the plain weighted value over all positions split so far, kept per child. It is subtracted once from the next target; it is not added again per step.

Why the order matters. LISP has a single unit of CHF 117,000. Rounding 3.5 shares to 4 gives the first child CHF 58,500 too much; the next positions take that back. With the sample data the stocks and bonds bring the drift down to about CHF 13 per child; splitting the cash then closes the gap to below one centime.
