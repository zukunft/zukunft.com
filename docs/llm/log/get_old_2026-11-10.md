## Lessons learned by llm

1. Switching on a test in `a_selected_test.php` is not done with the call alone: a test class of another directory
   needs its `include_once` and, for another namespace, its `use`; `php -l` cannot catch the missing class, because
   it is resolved only when the line runs, so grep for the include and the use before handing over the test run.
2. A new parameter gets its `@param` line in the same edit (`docs/llm/coding.md:125`), and a changed function that
   has only a line comment gets a full docblock, not only after the review.
3. Adding a docblock can change the generated description of the undocumented functions below it, so check the
   neighbours in `docs/code_functions_all.md` and give them their own docblock or name it as open.
