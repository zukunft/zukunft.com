Steps 1, 2 and 3 of "## fix Prio 0" of `docs/llm/pending.md`: activate the disabled tests, the stubs and the missing
tests, and deprecate. On request of the developer the three steps are in one file; each part is one prompt with its
own commit and at most three expected changes. The tables were written before the first code edit; the line numbers
are those of the start state (commit `4a78a1c5a` with the working tree of 2026-11-13: `http_old/` removed, the guard of

`pending.md` are outdated. Start: 151 `TODO Prio 0` in `src/main/php`, `src/test/php`, `api` and `http`.

a TODO that turns out less urgent gets a Prio 1, 2 or 3 with the concrete open work, never "done"; the test comes
first with a positive and a negative case; the smallest diff; Edit/Write only; the agents never commit and never run a
`/test/*` script. Each part reports the solved and the re-prioritised TODOs, the count left and the line balance.
