the user_message of a request is created once by the http resp. api entry point and
is passed down as the $msg parameter (docs/llm/state-and-messages.md), so every
"new user_message(" resp. "new Message(" below the entry points is an exception
that needs a comment behind the creation on the same line explaining why a local
message is needed - typically a buffer that is merged back or a message of
a different user; only a block of sibling buffers shares one comment above it
