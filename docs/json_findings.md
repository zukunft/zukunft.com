## format version

"version" is the version of the json format and not of the data, so it is matched against def::PRG_VERSION ("0.0.3"); a file that is behind is raised to it, a file that is ahead is only reported, because its data may need a newer program; the data version is the version of the content of the file and is raised by the author with every data change
